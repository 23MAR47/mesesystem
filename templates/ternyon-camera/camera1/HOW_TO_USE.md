# Camera — Ternyon şablonu

Bu klasör **Camera** projesinin tam kaynak kodu (bağımlılıklar hariç).

## Olduğu gibi çalıştır

```sh
npm install
npm run dev      # http://localhost:3000
# yayın için: npm run build && npm run start
```

## Yapay zekayla kendi projene uyarla

Klasörün tamamını yapay zeka kod asistanına ver (Claude, Cursor, Copilot, v0) ve istediğin kısımları kendi projene, istediğin çatıda uyarlamasını iste. İşletmenin adını, renklerini ve içeriğini yazman yeterli.
