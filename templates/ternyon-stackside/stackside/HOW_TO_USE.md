# Stackside — Ternyon şablonu

Bu klasör **Stackside** projesinin tam kaynak kodu (bağımlılıklar ve gizli anahtarlar hariç).

## Olduğu gibi çalıştır

```sh
npm install
npm run dev      # http://localhost:3000
# yayın için: npm run build && npm run start
```

> Proje bir ortam değişkeni istiyorsa (ör. API anahtarı) `.env.example` dosyasını `.env` (veya `.env.local`) olarak kopyalayıp doldur. Gizli bilgiler pakete bilerek konmadı.

## Yapay zekayla kendi projene uyarla

Klasörün tamamını yapay zeka kod asistanına ver (Claude, Cursor, Copilot, v0) ve istediğin kısımları kendi projene, istediğin çatıda uyarlamasını iste. İşletmenin adını, renklerini ve içeriğini yazman yeterli.
